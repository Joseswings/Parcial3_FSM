# Parcial 3: Implementación Física y HDL de Máquina de Estados (FSM)

**Estudiante:** Jose Guillermo Alas Alonzo

Este repositorio contiene la resolución práctica del Parcial 3, enfocada en la migración de un diseño de Máquina de Estados Finitos (FSM) desde la lógica de compuertas hasta su descripción en Hardware Description Language (SystemVerilog) y su implementación física en una tarjeta Basys 3.

## Estructura del Repositorio

El proyecto se divide en dos secciones principales correspondientes a los requerimientos de la evaluación:

* **[📁 Inciso 1: Timing Análisis](./Inciso1_Timing/)**
  Contiene el cálculo de la ruta crítica (Critical Path), márgenes de retardo (Setup/Hold Time Constraints) y la frecuencia máxima de operación real ($F_{max}$) utilizando datasheets de componentes físicos de Texas Instruments.

* **[📁 Inciso 2: Implementación en HDL (Vivado)](./Inciso2_HDL/)**
  Contiene los códigos fuente en SystemVerilog de la arquitectura factorizada (Moore y Mealy), el *Testbench* para la simulación de formas de onda y el archivo de restricciones (`.xdc`) para la placa Basys 3.
